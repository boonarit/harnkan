# ความเป็นส่วนตัว — หารกัน

หารกันเป็นบอทสำหรับคนสองคนในกลุ่ม LINE เดียวกัน ข้อมูลอยู่บนเครื่องของผู้ติดตั้งเอง ไม่มีการขายหรือแชร์ให้ใคร

## เก็บอะไร

- **ตัวตนใน LINE:** LINE user ID และชื่อที่แสดงของสมาชิก 2 คน, ID ของกลุ่ม
- **รายการค่าใช้จ่าย:** ชื่อรายการ ยอดเงิน ใครจ่าย วิธีหาร เวลา
- **สลิปและใบเสร็จ:** รูปที่ส่งในกลุ่ม, เลขอ้างอิงจาก QR ของสลิป (กันซ้ำ), ยอด ชื่อผู้โอน/ผู้รับที่อ่านได้
- **การตั้งค่า:** เบอร์พร้อมเพย์ของแต่ละคน, ชื่อบัญชีตามสลิป, เวลาสรุป, ยอดขั้นต่ำ
- **ประวัติการแก้ไข (audit log):** ใครแก้/ลบรายการไหน เมื่อไร
- ข้อความแชทที่ไม่ใช่รายการ (เช่น "กินข้าวยัง") **ไม่ถูกเก็บ** · รูปที่ไม่ใช่สลิป/ใบเสร็จ **ถูกลบทันที**

## เก็บที่ไหน

- ฐานข้อมูล SQLite และรูปสลิปอยู่ในเครื่องของผู้ติดตั้ง (`DATA_DIR`) ไม่ได้อยู่บนคลาวด์
- สำเนาสำรองฐานข้อมูลอยู่ที่ `BACKUP_DIR` บนเครื่องเดียวกัน (เก็บ 7 ชุดล่าสุด)
- **ส่งออกไปภายนอกเฉพาะ:**
  - LINE (ข้อความตอบกลับ, ดึงรูปที่ส่งในกลุ่ม, ตรวจการล็อกอินของ mini app)
  - ผู้ให้บริการ AI สำหรับอ่านยอดจากรูปสลิป/ใบเสร็จ — ค่าเริ่มต้นคือ **Google Gemini API** (หรือ Anthropic Claude API ถ้าผู้ติดตั้งเลือก) · ส่งเฉพาะรูปที่ส่งเข้ากลุ่ม ย่อขนาดก่อนส่ง · ส่งแค่รูป ไม่ส่งชื่อ LINE หรือประวัติรายการ
  - Gemini ใช้ key จากโปรเจกต์ที่**เปิด billing (paid tier) เท่านั้น** — ข้อมูลจาก free tier อาจถูกนำไปปรับปรุงผลิตภัณฑ์ของ Google จึงห้ามใช้กับสลิปจริง (ดู `docs/SETUP-CREDENTIALS.md`)
  - สลิปที่ QR บอกว่าเป็นสลิปซ้ำ จะไม่ถูกส่งให้ AI
- log ของระบบไม่มี token รูป หรือเนื้อหาสลิป

## ลบอย่างไร

- **ลบรายการเดียว:** พิมพ์ "ยกเลิก" (รายการล่าสุดของตัวเอง) หรือกดลบใน mini app
- **ลบข้อมูลทั้งหมดของกลุ่ม:** พิมพ์ **"ลบข้อมูลทั้งหมด"** ในกลุ่ม แล้วกดยืนยัน 2 ครั้ง → ลบรายการ สลิป รูป ยอด การตั้งค่า และประวัติของกลุ่มนั้นทันที กู้คืนไม่ได้
- **ลบอัตโนมัติ:** รูปสลิปเก่ากว่า 365 วัน (ปรับได้ในหน้าตั้งค่า) ถูกลบ เหลือแค่ตัวเลข · รูป QR พร้อมเพย์หมดอายุใน 24 ชั่วโมง
- สำเนาสำรองที่มีข้อมูลที่ลบไปแล้วจะหมดไปเองภายใน 7 วัน (สำรองวนทับ)
