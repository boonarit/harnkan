# ADR 001 · LINE-first (บอทในกลุ่ม + mini app) แทนแอปแยก

**สถานะ:** ใช้อยู่ · 2026-09

## บริบท
คู่ที่หารค่าใช้จ่ายกันคุยกันใน LINE อยู่แล้วทั้งวัน การให้เปิดแอปอีกตัวเพื่อจดทุกบิลคือจุดที่คนเลิกใช้

## ตัดสินใจ
- จุดบันทึกหลักคือ **กลุ่ม LINE**: พิมพ์ "กาแฟ 90" หรือส่งสลิป บอทตอบการ์ดเดียว
- ข้อความที่ไม่ใช่รายการ บอท **เงียบ** (แชทยังเป็นของคู่)
- งานที่ต้องใช้จอ (แก้ไข ประวัติ QR ตั้งค่า) อยู่ใน **LINE mini app / LIFF** ที่เปิดจากในแชท
- สรุปวันละครั้ง 21:00 เป็นยอดโอนเดียว แทนการโอนทุกบิล

## ผลที่ตามมา
- ผูกกับแพลตฟอร์ม LINE (Messaging API quota, LIFF) — ยอมรับ เพราะผู้ใช้เป้าหมายอยู่ใน LINE
- ต้องจำกัด 2 คนต่อกลุ่ม · ต้องออกแบบ parse ให้ "เงียบถ้าไม่แน่ใจ"
- โหมดเดโมจำลองแชทได้โดยไม่ต้องมีบัญชี LINE
