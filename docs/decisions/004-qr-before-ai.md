# ADR 004 · ถอด QR ของสลิปก่อนใช้ AI

**สถานะ:** ใช้อยู่ · 2026-09

## บริบท
สลิปโอนเงินไทยมี QR (Slip Verify) ที่มีรหัสธนาคาร + เลขอ้างอิงธุรกรรม · การส่งทุกรูปให้ AI มีค่าใช้จ่ายและอาจอ่านผิด

## ตัดสินใจ
1. อ่าน QR ด้วย `jsqr` + `promptparse` ก่อนเสมอ (ในเครื่อง ฟรี เร็ว) → ได้ `transRef`
2. `transRef` ซ้ำ → ตอบ "สลิปนี้บันทึกแล้ว" **ไม่เรียก AI** (unique ใน DB กันส่งซ้ำ)
3. ค่อยให้ Claude อ่านยอด/ชื่อ/ร้าน (QR ไม่มียอดเงิน) · บังคับผลเป็น JSON ผ่าน tool schema
4. ความมั่นใจต่ำหรือไม่มียอด → ถามกลับ 1 คำถาม · มีเพดานจำนวนรูปต่อวันต่อคู่

## ผลที่ตามมา
- กันบันทึกซ้ำได้แน่นอนแม้ AI อ่านต่างกันแต่ละครั้ง
- ใบเสร็จร้าน (ไม่มี QR) ยังพึ่ง AI อย่างเดียว
- AI ล่ม → ระบบยังใช้ได้ (ขอให้พิมพ์ยอดแทน)
