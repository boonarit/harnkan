# ADR 003 · เงินเป็นสตางค์ (integer) ทุกที่

**สถานะ:** ใช้อยู่ · 2026-09

## บริบท
`0.1 + 0.2 !== 0.3` · การหารครึ่งยอดคี่ (฿1.01) ต้องได้ผลที่รวมกลับเท่ายอดบิลเสมอ และทั้งคู่ต้องเห็นตัวเลขเดียวกัน

## ตัดสินใจ
- เก็บและคำนวณเป็น **สตางค์ (integer)** ใน DB, API, domain · แปลงเป็นบาทเฉพาะตอนแสดงผล
- parse ข้อความ ("1,250", "฿90", "63.5") → สตางค์ด้วยการแยก string ไม่ผ่าน float
- เศษสตางค์คี่ของการหารครึ่ง **สลับกันรับตามลำดับ id รายการ** (ผลคงที่ ยุติธรรมในระยะยาว)
- property test: ผลรวม shares = ยอดบิล เสมอ (1000 เคส)

## ผลที่ตามมา
- API รับยอดเป็นจำนวนเต็มเท่านั้น (ทศนิยม = 400)
- QR พร้อมเพย์แปลงเป็นบาทตอนสร้าง payload จุดเดียว
